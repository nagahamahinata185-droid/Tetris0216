# ゲームタイトル

ASCIIテトリス（改良版）

## ゲームの概要

上から落ちてくるブロック([ ])を組み合わせて崩していくゲームです。
ルールは上から落ちてくるブロックを移動・回転させて横一列にそろえるとラインが消えてスコアが加算され、
ブロックが画面の上まで積み上がるとゲームオーバーになります。


## 動作環境

- OS：Windows / macOS / Linux
- Python：Python 3.7 以上
- 必要なライブラリ：追加ライブラリ不要

## 操作方法

A / ←（左矢印キー）：ブロックを左へ1マス移動する

D / →（右矢印キー）：ブロックを右へ1マス移動する

W / ↑（上矢印キー）：ブロックを時計回りに90度回転させる

S / ↓（下矢印キー）：ブロックの落下速度を早める（ソフトドロップ）

Space（スペースキー）：ブロックを一番下まで一気に落下させて固定する（ハードドロップ）

P：ゲームを一時停止（PAUSED）する／もう一度押して再開する

R：ゲームをリセットして最初からやり直す

Q：ゲームを終了する

## 追加・改良した機能
・変更点01 1000点ボーナスプログラム

・変更点02 1マス埋めるブロックの追加

・変更03 爆弾ブロックの追加

### 改良機能01：（1000点ボーナスプログラム）
clear_lines() メソッドの中を変更。
ラインを消去して盤面（self.board）を更新した直後に、盤面上のすべてのマスが空白（' '）になっているかをall() 関数で判定し、ブロックが残っていない場合、通常の消去スコアに加えて1000点の特別ボーナスを加算するようにした。

### 改良機能02：（1マス埋めるブロック）
SHAPES 辞書に追加。
既存のプログラムがSHAPES辞書から自動でブロックを抽選する仕組みを利用し、座標 (1,1)だけの1マスブロックを新しく定義して追加してみた。

### 改良機能03：（爆弾ブロック）
SHAPES 辞書 と Tetris.lock() メソッドの変更
BOMBという名前の1マスブロックを追加し、lock()（ブロックが固定される瞬間）で「もし固定されたブロックがBOMBだったらその周囲1マスの範囲を空白 ' ' に書き換える」処理をする。種類がBOMBの場合のみ2重ループで周囲3×3マスの座標を範囲チェックしながら空白にリセットする特殊効果を追加。
